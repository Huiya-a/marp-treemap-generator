## 二、核心模块（CLI 路径）

数据流：`Excel → data_loader → layout → HTML → Marp Markdown`

### 2.1 `generate_treemap_md.py` — CLI 入口 + HTML 渲染

**职责**：读取 Excel 数据，计算布局结构，生成 Marp 兼容的 Markdown 文件。

**关键函数**：

| 函数 | 作用 |
|------|------|
| `main()` | CLI 入口，解析参数，遍历 Excel 文件调用 `generate_marp_md` |
| `generate_marp_md(domain_name, data, output_path, proportional_width, slide_height)` | 生成完整的 Marp Markdown 文件（frontmatter + CSS + HTML） |
| `_compute_structure(data)` | 两遍布局：第 1 遍测量内容边界，自适应画布；第 2 遍最终布局 + CSS 像素转换 |
| `_render_group_html(group_data)` | 渲染单个组的 HTML（模块格子 + CSS 变量） |
| `_wrap_text(mod_name)` | CJK 智能换行，插入 `<br>` 标签 |
| `_find_excel(data_dir, input_name)` | 按前缀/包含匹配查找 Excel 文件 |

**调用关系**：
```
main()
  ├── load_data_from_excel()          # 来自 data_loader
  ├── _compute_structure(data)
  │     ├── _layout_many_groups()     # 组数 ≥ 6 时
  │     ├── compute_modules_per_row() # 组数 < 6 时
  │     ├── compute_optimal_column_count()
  │     ├── _assign_groups_to_columns()
  │     └── _adjust_mpr_for_balance()
  └── generate_marp_md()
        └── _render_group_html()      # × N 个组
```

### 2.2 `src/config.py` — 全局配置

**职责**：定义所有布局常量（自然单位）和配色方案。无函数，纯常量文件。

**主要常量分类**：

| 分类 | 代表常量 | 说明 |
|------|---------|------|
| 画布尺寸 | `CANVAS_W`, `CANVAS_H`, `CANVAS_W_PX`, `CANVAS_H_PX` | 自然单位 13.33×7.5 → 像素 1280×720 |
| 画布高度 | `SLIDE_HEIGHT_PX` | 可自定义的幻灯片高度（默认720px，范围400-720） |
| 模块尺寸 | `MODULE_W`, `MODULE_H`, `MODULE_GAP_X`, `MODULE_GAP_Y` | 模块矩形 3:1 宽高比 |
| 组内部 | `HEADER_H`, `HEADER_GAP`, `GROUP_PAD_BOTTOM`, `GROUP_PAD_X` | 标题栏、间距、内边距 |
| 画布边距 | `OUTER_PAD_X`, `OUTER_PAD_TOP`, `OUTER_PAD_BOTTOM` | 外边距 |
| 间距 | `COL_GAP`, `ROW_GAP` | 列间、组间间距 |
| 配色 | `GROUP_BG`, `GROUP_HEADER_COLOR`, `MODULE_BG_COLOR` 等 | 背景色、边框色、文字色 |
| 布局控制 | `TARGET_RATIO`, `ADJUST_MPR` | 目标宽高比、mpr 平衡开关 |

### 2.3 `src/data_loader.py` — Excel 数据解析

**职责**：从 Excel 文件中读取应用架构数据，返回统一的数据结构。

**关键函数**：

| 函数 | 作用 |
|------|------|
| `load_data_from_excel(filepath)` | 读取 Excel，返回 `(domain_name, {group: [modules]})` |
| `load_data_from_json(filepath)` | 备用方案，从 JSON 加载数据 |

**Excel 格式要求**：Sheet 名含"应用模块清单"，第 3 行起，B 列=域名，D 列=组名，G 列=模块名。

### 2.4 `src/layout.py` — 核心布局算法

**职责**：计算每个组的自然尺寸，将组分配到各列，计算缩放因子，放置模块坐标。

**两条代码路径**：

| 条件 | 路径 | 核心函数 |
|------|------|---------|
| 组数 < 6 | 动态列数 + 平衡评分 | `compute_optimal_column_count` → `_assign_groups_to_columns` → `_adjust_mpr_for_balance` |
| 组数 ≥ 6 | 固定 mpr=3 贪心填充 | `_layout_many_groups` → `_find_combination` |

**关键函数**：

| 函数 | 作用 |
|------|------|
| `compute_modules_per_row(n)` | 根据模块数计算最佳每行模块数（目标 ratio ≈ 1.5） |
| `compute_group_size(n, mpr)` | 计算组的自然尺寸（宽 × 高） |
| `_raw_group_size(n, mpr)` | 组的原始尺寸计算（含标题栏、间距、内边距） |
| `compute_optimal_column_count(group_info)` | 尝试 2~4 列，综合评分选最优 |
| `_assign_groups_to_columns(group_info, ncols)` | 贪心分配，`score = module_dev + vr_dev²` |
| `_adjust_mpr_for_balance(col_groups)` | 调整 mpr 使列间高度均衡 |
| `_pack_groups_into_rows(groups, col_width)` | 列内组按宽度贪心打包成行 |
| `_layout_many_groups(data)` | 组数 ≥ 6 时的专用布局 |
| `treemap_layout(data)` | 主布局函数（用于 matplotlib 渲染） |

## 三、GUI 模块

### 3.1 `src/app.py` — GUI 启动入口

**职责**：创建 `QApplication`，设置字体，启动 `MainWindow`。

```python
def main():
    app = QApplication(sys.argv)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

### 3.2 `src/gui/main_window.py` — 主窗口

**职责**：组装左右面板，管理生成工作线程，协调各组件之间的信号通信。

**核心类**：

| 类 | 作用 |
|----|------|
| `GenerateWorker(QThread)` | 后台线程，执行 Excel → MD → PNG/PPTX/HTML 的生成流程 |
| `MainWindow(QMainWindow)` | 主窗口，包含 UI 布局、信号连接、参数应用逻辑 |

**关键状态变量**（`MainWindow`）：

| 变量 | 类型 | 作用 |
|------|------|------|
| `_generated_md_files` | `{excel: md}` | Excel 到 Markdown 的路径映射 |
| `_original_params` | `{md: {key: val}}` | 首次生成时 config 默认值快照 |
| `_initial_css` | `{md: {key: val}}` | 首次生成时文件中实际 CSS 像素值（缩放基准） |
| `_pending_params` | `dict` 或 `None` | 暂存的待应用参数 |
| `_session_processed` | `set` | 本次会话已处理过的 Excel 文件（会话级复用） |

**关键信号流**：

```
FileSelector.files_changed → MainWindow._on_files_changed → FileInfoWidget.load_file
ParamsPanel.params_changed → MainWindow._on_params_changed → 暂存 _pending_params
ParamsPanel.module_color_applied → MainWindow._on_module_color_applied → apply_module_color
GenerateWorker.progress/log/finished → MainWindow._on_progress/_on_log/_on_finished
```

**PNG 裁剪功能**：

| 函数 | 作用 |
|------|------|
| `_crop_transparent_area(png_path)` | 裁剪 PNG 底部的透明区域 |

**裁剪逻辑**：
1. 将 PNG 转换为 RGBA 模式
2. 检测 alpha 通道，找到最后一行非透明像素
3. 裁剪图片到该行（精确裁剪，无额外边距）
4. 保存裁剪后的图片

### 3.3 `src/gui/file_selector.py` — 文件选择器

**职责**：提供 Excel 文件的选择、拖拽导入、历史记录管理。

**核心类**：`FileSelector(QWidget)`

**关键功能**：
- 添加文件 / 添加文件夹 / 拖拽导入
- 最近文件历史记录（`QSettings` 存储）
- 右键菜单：移除选中 / 清空列表
- 信号：`files_changed(list)`, `current_file_changed(str)`

### 3.4 `src/gui/file_info_widget.py` — 文件信息预览

**职责**：显示选中 Excel 文件的元数据和数据树预览。

**核心类**：`FileInfoWidget(QWidget)`

**关键功能**：
- 显示文件名、Sheet 名、域名称、组数、模块总数
- 树形展示 `{组: [模块]}` 结构
- 内部缓存 `_cache` 避免重复解析同一文件

### 3.5 `src/gui/preview_widget.py` — 图片预览

**职责**：显示生成的架构图，支持多图片左右切换。

**核心类**：`PreviewWidget(QWidget)`

**关键功能**：
- 图片自适应缩放显示
- 左右箭头切换多张图片（`_image_history`）
- 图片计数显示（如 "3 / 5"）
- 支持 PNG 图片和 MD 文件路径

### 3.6 `src/gui/params_panel.py` — 参数调整面板

**职责**：提供颜色、间距、字体、布局等参数的 UI 控件，发射参数变更信号。

**核心类**：`ParamsPanel(QWidget)`

**关键功能**：
- 7 个 `ColorButton`（颜色选择器），使用 `setFixedWidth(85)` 对齐
- 多个 `NoWheelSpinBox` / `NoWheelDoubleSpinBox`（防滚轮误操作）
- 模板管理按钮（保存 / 加载 / 重置）
- 单模块调色区（输入模块名 + 选颜色 + 应用）
- 批量调色按钮（打开 `ModuleColorDialog`）
- 画布高度调整（400-720px，通过 `slide_height_spin` 控制）
- 信号：`params_changed(dict)`, `module_color_applied(str, str)`, `batch_module_color_applied(list, str)`

**已隐藏的选项**（暂时不可见）：
- 启用MPR平衡调整（`_mpr_container`）
- 目标宽高比（`_ratio_container`）
- 模块行高（`_lh_container`）

### 3.7 `src/gui/template_manager.py` — 模板管理

**职责**：参数配置模板的保存、加载、删除。

**核心类**：

| 类 | 作用 |
|----|------|
| `TemplateManager` | 模板文件的 CRUD 操作（JSON 格式） |
| `TemplateDialog` | 模板选择对话框（保存时输入名称，加载时列表选择） |

**存储位置**：`~/.架构图生成器/templates/`

### 3.8 `src/gui/md_editor.py` — Markdown CSS 正则编辑

**职责**：直接编辑已生成 `.md` 文件中的 CSS 值和 HTML inline 变量，无需重新运行布局算法。

**关键函数**：

| 函数 | 作用 |
|------|------|
| `extract_params_from_md(md_path)` | 从 md 文件中提取当前所有可调 CSS 参数值（包括 frontmatter 中的 height） |
| `apply_params_to_md(md_path, new_params, original_params, css_baseline)` | 按比例缩放并写入新的 CSS 值（包括 frontmatter height 和 CSS section height） |
| `apply_module_color(md_path, module_name, color)` | 为指定模块设置独立背景色（CSS class 方式） |
| `_sub_in_css_blocks(content, pattern, replacement)` | 在 CSS 规则块内执行正则替换，不跨越 `}` 边界 |
| `_extract_css_blocks(content)` | 将 CSS 文本拆分为独立的规则块列表 |

**画布高度调整机制**：
1. 替换 frontmatter 中的 `height: XXXpx`（只在 `style:` 之前的部分）
2. 替换 CSS 中 `section` 选择器的 `height: XXXpx !important`
3. 不会影响 CSS 中其他元素的 `height: 100%` 等值

**模块调色机制**：
1. 用模块名 MD5 哈希生成 `mc-{hash}` class
2. 在 frontmatter style 块插入 `.mc-xxx { background: color !important; }`
3. 在目标 `<div class="module">` 上追加 `mc-xxx` class
4. 用 `(?!s)` 负向前瞻排除 `.modules` 容器

### 3.9 `src/gui/module_color_dialog.py` — 批量模块调色对话框

**职责**：展示当前文件所有模块的树形列表，支持多选 + 选色 + 批量应用。

**核心类**：`ModuleColorDialog(QDialog)`

**关键功能**：
- 左侧 `QTreeWidget` 展示 `{组: [模块]}` 树，支持 Ctrl 多选
- 右侧操作区：全选 / 取消全选 / 颜色选择 / 已选计数 / 应用按钮
- 信号：`colors_applied(list, str)` — 选中的模块名列表 + 颜色值

### 3.10 `src/gui/collapsible_section.py` — 可折叠面板

**职责**：提供带标题栏的可折叠容器，点击标题栏展开/收起内容。

**核心类**：`CollapsibleSection(QWidget)`

**关键功能**：
- 标题按钮点击切换展开/收起
- 信号：`toggled(bool)` — 展开时 True，收起时 False
- 三个面板（文件选择、文件信息、参数调整）共用外层 `QScrollArea`

## 四、模块间调用关系

```
app.py
  └── MainWindow
        ├── FileSelector
        │     └── files_changed → MainWindow._on_files_changed
        ├── FileInfoWidget
        │     └── load_file ← MainWindow._on_files_changed
        ├── ParamsPanel
        │     ├── params_changed → MainWindow._on_params_changed
        │     ├── module_color_applied → MainWindow._on_module_color_applied
        │     └── batch_module_color_applied → MainWindow._on_batch_module_color_applied
        ├── PreviewWidget
        │     └── set_image / add_image ← MainWindow._on_file_generated
        ├── GenerateWorker (QThread)
        │     ├── load_data_from_excel()    ← data_loader.py
        │     ├── generate_marp_md()        ← generate_treemap_md.py
        │     ├── marp CLI (subprocess)
        │     └── _crop_transparent_area()  ← PNG 裁剪
        ├── md_editor
        │     ├── apply_params_to_md()      ← MainWindow._on_apply_params
        │     └── apply_module_color()      ← MainWindow._on_module_color_applied
        ├── ModuleColorDialog
        │     └── colors_applied → MainWindow._on_batch_module_color_applied
        └── TemplateManager
              └── save / load ← ParamsPanel
```
