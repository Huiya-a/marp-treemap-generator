# Marp Treemap Generator

将应用架构 Excel 数据转换为 Treemap 矩形图，输出 Marp 兼容的 Markdown，可一键转为 PPT 幻灯片。

## 效果预览

每页展示一个应用域的 Treemap 包含关系图，包含域标题、应用组（蓝色标题栏）和模块格子。

## 功能特性

- ✅ **命令行模式**: 批量生成 Markdown 文件
- ✅ **GUI 模式**: 图形界面，支持实时预览和参数调整
- ✅ **文件选择**: 支持选择单个或多个 Excel 文件，支持拖拽导入
- ✅ **参数调整**: 可以调整颜色、间距、字体、画布高度等参数
- ✅ **批量处理**: 支持多文件批量生成
- ✅ **多种输出**: 支持 Markdown、PPTX、PNG、HTML 格式及组合导出
- ✅ **模板管理**: 保存和加载参数配置模板
- ✅ **历史记录**: 使用QSettings存储最近打开的文件
- ✅ **快捷键**: Ctrl+O 打开、Ctrl+S 保存、Ctrl+Enter 生成、Ctrl+Q 退出
- ✅ **可折叠面板**: 左侧各区域支持展开/收起
- ✅ **模块调色**: 单模块调色 + 批量多模块调色，支持重复修改
- ✅ **会话级复用**: 已生成的 Markdown 在同一会话内不重复生成
- ✅ **画布高度调整**: 支持调整幻灯片高度（400-720px），自动裁剪透明区域
- ✅ **自动裁剪**: PNG 生成后自动裁剪底部透明像素

## 快速开始

### 安装依赖

```bash
# 命令行模式
pip install openpyxl numpy

# GUI 模式（额外需要 PySide6）
pip install "PySide6>=6.5.0" "openpyxl>=3.1.0" "numpy>=1.24.0"

# 安装 Marp CLI（转 PPT 用）
npm install -g @marp-team/marp-cli
```

### 命令行模式

```bash
# 生成 Markdown
python generate_treemap_md.py

# 转 PPTX
marp output/*.md --pptx

# 转 PNG 图片
marp output/*.md --images png --allow-local-files
```

### GUI 模式

```bash
# 启动 GUI 应用
python src/app.py

# 或者双击启动脚本 (Windows)
启动应用.bat
```

## 命令行用法

```bash
# 处理 data/ 下所有 Excel 文件
python generate_treemap_md.py

# 按前缀/包含匹配处理单个文件
python generate_treemap_md.py 03        # 匹配 "03 开头" 的文件
python generate_treemap_md.py 纪检监察   # 包含匹配

# 多文件按列数比例分配宽度（使不同幻灯片列宽可比）
python generate_treemap_md.py --proportional-width
```

## GUI 使用说明

### 操作流程

#### 第一步：选择 Excel 文件
1. 点击"添加文件"按钮，选择一个或多个 Excel 文件
2. 或点击"添加文件夹"按钮，批量添加文件夹中的所有 Excel
3. 或直接拖拽 Excel 文件到文件列表区域
4. 选中文件后，右侧会显示 Excel 的元数据和数据结构预览

#### 第二步：生成初始架构图
1. 点击"生成架构图"按钮
2. 等待生成完成（进度条会显示进度）
3. 右侧预览区域会显示生成的架构图
4. 日志区域会显示详细的生成信息

#### 第三步：调整参数（可选）
根据需要调整左侧面板中的参数，每个参数都会影响图片中的特定位置：

#### 第四步：应用参数
1. 调整完参数后，点击"应用参数到 Markdown"按钮
2. 参数会立即应用到已生成的 Markdown 文件
3. 右侧预览会自动刷新，显示调整后的效果

#### 第五步：重新生成图片
1. 如果需要导出 PNG/PPTX，点击"生成架构图"按钮
2. 新的图片会自动保存到 `output/` 目录

### 参数调整详细说明

#### 🎨 颜色设置

| 参数 | 影响位置 | 说明 |
|------|----------|------|
| 组背景色 | 应用组的背景区域 | 蓝色标题栏下方的灰色背景 |
| 组标题色 | 应用组的标题栏 | 蓝色标题栏的背景色 |
| 模块背景色 | 模块格子的背景 | 每个模块格子的浅蓝色背景 |
| 域背景色 | 最外层域框的背景 | 整个域框的浅灰色背景 |
| 域边框色 | 最外层域框的边框 | 域框的深蓝色边框 |
| 域标题色 | 域名称文字 | 顶部"纪检监察域"等标题文字颜色 |
| 模块边框色 | 模块格子的边框 | 每个模块格子的白色边框 |

**示例**：将"组标题色"从蓝色改为红色，所有应用组的标题栏都会变成红色。

#### 📐 间距设置

| 参数 | 影响位置 | 说明 |
|------|----------|------|
| 域内边距 | 域框边框 → 内容之间 | 增大值会让内容更靠近域框中心，减少值让内容更贴近边框 |
| 列内组间距 | 同一列内各组之间 | 增大值会让组与组之间更分离，减少值让布局更紧凑 |
| 标题下方间距 | 域标题 → 内容之间 | 增大值会让标题和内容之间更分离 |

**示例**：将"列内组间距"从 8px 改为 16px，同一列内的组之间会有更大的空白。

#### 🔤 字体设置

| 参数 | 影响位置 | 说明 |
|------|----------|------|
| 模块字号 | 模块格子内的文字 | 增大值让模块名称文字更大 |
| 标题字号 | 应用组标题栏文字 | 增大值让"数字办案应用"等标题更大 |
| 域标题字号 | 域名称文字 | 增大值让"纪检监察域"等域标题更大 |

**示例**：将"模块字号"从 14px 改为 18px，模块格子内的文字会更大更清晰。

#### ⭕ 圆角设置

| 参数 | 影响位置 | 说明 |
|------|----------|------|
| 域外框圆角 | 域框的四个角 | 增大值让域框角更圆润，设为 0 则是直角 |
| 组圆角 | 应用组的四个角 | 增大值让应用组角更圆润 |
| 模块圆角 | 模块格子的四个角 | 增大值让模块格子角更圆润 |

**示例**：将"域外框圆角"从 12px 改为 0px，域框会变成直角矩形。

#### 📏 边框设置

| 参数 | 影响位置 | 说明 |
|------|----------|------|
| 域边框宽度 | 域框的边框粗细 | 增大值让域框边框更粗，设为 0 则无边框 |

**示例**：将"域边框宽度"从 3px 改为 6px，域框边框会更粗更明显。

#### 📐 布局设置

| 参数 | 影响位置 | 说明 |
|------|----------|------|
| 画布高度 | 整个幻灯片的高度 | 减小值会裁剪底部透明区域，增大值无效（Marp 限制） |

**说明**：
- 默认高度 720px，可调整范围 400-720px
- 减小高度时，内容会自动裁剪底部透明区域
- 增大高度无效，因为 Marp CLI 始终生成 1280×720 的图片

### 模块调色功能

#### 单模块调色
1. 在"模块调色"区域输入模块名称（如"业务审批流配置"）
2. 点击颜色按钮选择颜色
3. 点击"应用"按钮
4. 该模块会立即变成指定颜色

#### 批量调色
1. 点击"批量调色"按钮
2. 在弹窗中按住 Ctrl 键多选模块
3. 选择颜色
4. 点击"应用"按钮
5. 所有选中的模块会变成指定颜色

**注意**：模块调色会覆盖之前的颜色设置，多次调色以最后一次为准。

## Excel 数据格式

| 要求 | 说明 |
|------|------|
| Sheet 名称 | 需包含"应用模块清单"，或取第二个 sheet |
| 数据起始行 | 第 3 行 |
| B 列 | 应用域名称（作为 slide 标题） |
| D 列 | 应用组名称 |
| G 列 | 一级应用模块名称 |

## 数据流

```
Excel → data_loader → layout → HTML 生成 → Marp Markdown → PNG裁剪 → PPTX/PNG
```

## 画布高度调整说明

画布高度功能允许用户调整 Marp 幻灯片的高度（400-720px）：

- **不影响模块缩放**：模块格子尺寸保持不变
- **自动裁剪**：当高度小于内容高度时，自动裁剪底部透明区域
- **限制范围**：最大高度 720px（Marp CLI 默认高度），超过会导致内容被截断

## 手动调整样式

生成的 Markdown 文件可以直接编辑，修改 CSS 属性即可调整样式。涵盖：字号、内边距、间距、颜色、圆角、模块大小、字体、换行等。
